# Lectures

## Lecture 15

[Open the interactive lecture](https://shaevitz.github.io/567-Crowd-Control/lectures/lecture-15-animal-interaction-rules.html). Slides, simulations, and movies run in the browser without Python. The **Show Python** button displays the equivalent code.

To run the companion, clone this repository or use **Code → Download ZIP**, keeping `lectures/`, `data/`, and `media/` together. Install the root `environment.yml`, then open `lecture-15-animal-interaction-rules.ipynb` with the `swarming-course` kernel. Downloading the notebook alone does not include its input data.
